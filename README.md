# SmartStock AI

An AI-powered inventory management system that helps small retailers track stock, spot low inventory early, and decide what to reorder.

## Problem
Small businesses often run out of stock or overstock because they track inventory manually and notice problems too late.

## Features
- Sign-up, login and logout
- Product management: add, edit, delete, search
- Stock in/out updates with a change history
- Dashboard with total products, low-stock count and recent activity
- Low-stock warnings based on reorder levels
- Reports & analytics with charts and CSV export
- AI assistant that answers questions about your inventory
- AI restocking suggestions

## Tech Stack
- Frontend: React, Vite, TypeScript
- Backend/Database: [Firebase Firestore, Express server]
- AI: Google Gemini API
- Built with: Google AI Studio, Stitch (UI design)

## How to Run
1. Clone the repo
2. Run `npm install`
3. Copy `.env.example` to `.env` and add your own keys
4. Run `npm run dev`
